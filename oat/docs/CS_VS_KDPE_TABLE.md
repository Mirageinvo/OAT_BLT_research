# CS (vote) vs KDPE — основные и seed-прогоны

Протокол: N=8, K=8, T=1.0, topk=10, 50 фиксированных сцен (`test_start_seed=10000`), 5 повторов × 50 эпизодов, aic4.
SR в %, ± = std по повторам. Δ = CS − KDPE (плюс = наш метод CS лучше).

- **Основные** — текущие прогоны без `--policy_seed`, это числа для статьи.
- **Seed** — те же ячейки с `--policy_seed 0` (повтор i сидится 0+i). Нужны только для проверки воспроизводимости, с основными не смешиваем.
